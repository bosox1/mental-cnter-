# Центр ментального здоров'я — ІФНМУ

Статичний сайт на React + Vite + Tailwind v4. П'ять сторінок, спільні хедер і футер.

## Запуск

```bash
npm install
npm run dev      # локально, http://localhost:5173
npm run build    # збірка в dist/
```

## Структура

```
src/
  data/site.js        ← весь текст і контакти. Правити контент тут.
  components/         Header, Footer, Layout, Container, LabelRule, BookingButton, BackLink
  pages/              Home, About, Services, News, Contacts, NotFound
public/images/        картинки (див. нижче)
```

Маршрути: `/` `/about` `/services` `/news` `/contacts`, решта → 404.

Іконки підтягуються з Iconify по іменах із макета (`carbon:education`, `hugeicons:doctor-03`
та ін.) — експортувати їх не треба.

## Картинки

Усі картинки вже лежать у `public/images/` під зрозумілими іменами (`hero.png`,
`principle-1..4.jpg`, `news-1..5.png`, `partner-*.png` і т.д.). Щоб замінити будь-яку —
достатньо покласти файл з тим самим іменем, шляхи прописані в `src/data/site.js`.

Чого поки немає:

- фото Негребецької Майї — картка показується з жовтою заглушкою та ініціалом;
- фото Синюка Ігоря — те саме (ти сказав, що не треба, але файл `Rectangle_1_Синюк.png`
  у мене на руках є; скажи, якщо все ж додати).

Щоб прибрати когось із команди зовсім — видалити відповідний обʼєкт з масиву `about.team`
у `src/data/site.js`.

## Деплой на Netlify

`netlify.toml` уже налаштований: команда `npm run build`, тека `dist`, SPA-редирект на
`index.html` (без нього прямі посилання типу `/news` віддавали б 404).

1. Залити репозиторій на GitHub.
2. Netlify → Add new site → Import from Git → вибрати репозиторій. Налаштування підхопляться
   з `netlify.toml`.
3. Site settings → Domain management → Add custom domain → вписати субдомен.

Далі потрібен системний адміністратор ІФНМУ: у DNS-зоні `ifnmu.edu.ua` треба додати запис

```
CNAME   <субдомен>   <ім'я-сайту>.netlify.app
```

Сертифікат Let's Encrypt Netlify випустить сам, щойно запис пошириться.

## Відомі відкриті питання

- Instagram і Facebook у футері приховані, бо посилань на них немає. Щойно з'являться —
  вписати в `src/data/site.js`, блок покажеться сам.
- Кнопка «Записатися» веде на Google-форму. Варіант «Увійти» з макета не реалізований —
  особистого кабінету не передбачено.
- Мобільне меню зроблено бургером. У макеті пункти намальовані просто списком у шапці,
  без явного стану «відкрито/закрито» — це моя інтерпретація, легко переробити.
- У текстах макета було кілька друкарських помилок, я їх виправив: «хроніфікікації» →
  «хроніфікації», «щосереди 0 18:00» → «щосереди о 18:00», «Принцип мультидисциплінарних
  командах» → «...команд». Варто, щоб замовник вичитав тексти повністю.
